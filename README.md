# Classificação Automática de Autos de Infração Ambiental utilizando PLN

Projeto desenvolvido na disciplina de Planejamento e Gestão de Projetos da
Universidade Federal da Fronteira Sul (UFFS).

## Problema

Autos de infração ambiental possuem descrições textuais que precisam ser
associadas a categorias de infração. O projeto investiga a utilização de
Processamento de Linguagem Natural e Aprendizado de Máquina para automatizar
essa classificação.

## Objetivo

Desenvolver e avaliar uma solução capaz de classificar automaticamente
descrições textuais de autos de infração ambiental em suas respectivas
categorias.

## Dados

Serão utilizados dados públicos disponibilizados pelo Instituto Brasileiro
do Meio Ambiente e dos Recursos Naturais Renováveis (Ibama).

## Tecnologias previstas

- Python
- Pandas
- Scikit-learn
- Bibliotecas de Processamento de Linguagem Natural
- Google Colab
- Streamlit
